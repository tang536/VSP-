## v1.0.7

### 网络视频预览（重点修复）
- 网络视频预览从系统 `MediaPlayer` / `VideoView` 换成 **ExoPlayer（Media3 1.6.1）**：
  下载正常、预览却打不开的 HLS 相对分片、DASH 分离流、FLV / MKV 都能正确播放。
- 画面流和音轨分离的视频（B 站等）用 `MergingMediaSource` 把最佳音轨合起来播，
  不再出现「有画面没声音」。
- 预览直接复用解析结果里的 `url`，不再每次重新跑 `get_preview_url`：
  yt-dlp 的 `format_id` 两次解析可能变化、链接也可能在等待中过期，
  这正是「同一个视频有时能预览、有时不能」的原因。
- 首次播放失败时自动依次尝试：去掉音轨 → 重新解析拿新直链 → 弹诊断；
  重新解析会同时带回容器类型和配套音轨，避免画面 / 声音来自两次提取。
- 请求头改为桌面 UA + **原页面 Referer**（以前普通直链用 CDN 域名拼 Referer，预览 403）。
- 本机转发代理仍用于音频预览，并同步修正 Referer；Range / HEAD 转发保持不变。

### 兼容性
- 本地视频继续走 `VideoView`，本地 / `content://` 音频继续走 `MediaPlayer`，
  原有观看层、倍速、音量、横竖屏、进度条行为不变。
- 新增 Media3 依赖，APK 体积约 30.3 MiB。
