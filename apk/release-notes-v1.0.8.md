## v1.0.8

### 更新弹窗（重点调整）
- 「发现新版本」改为与应用主题一致的圆角卡片：居中标题、版本 / 安装包大小、
  「更新内容：」说明区，底部是橙色描边的「下载并安装」与次要的「取消」。
- 点「下载并安装」后不再跳出一个新的进度框，而是在**同一个弹窗**的下半部分
  换成进度条：同一行显示「已下载 / 总大小 · 实时速度」，百分比单独显示在进度条上方。

### 下载可靠性
- 下载状态写入本地：关闭弹窗、退到后台、进程被系统回收后重新打开更新，
  会接着原来的 `.part` 文件继续，不会从 0 重新下载。
- 支持 HTTP `Range` 断点续传（GitHub 等支持 Range 的源）；源站不支持 Range 时
  自动从头重下，但不会卡死。
- 切网 / 息屏 / 弱网导致连接中断时，前台服务会保留已下载部分并自动重试；
  断网期间显示「等待网络恢复…」，网络恢复后自动继续。
- 注册网络状态回调、持有下载期间的唤醒锁，服务改为 `START_STICKY` 且
  `stopWithTask="false"`，退出任务列表不终止下载。
- 下载完成后弹窗切换为「下载完成」，提供「立即安装 / 稍后」；通知栏也可直接安装。
  重新点检查更新会优先认出已下载完的安装包，而不是重新下载。
- 通知栏保留进度、已下载 / 总大小、实时速度和「取消下载」；下载中断时增加
  「继续下载」动作。
