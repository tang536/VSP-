修「提示 json 意外结束」：B 站接口以前只请求一次、直接 json.loads，手机网络被风控或运营商拦截、返回 HTML/空包时，会把「Expecting value / End of input」这类原始报错原样弹给用户。

现在接口层会先按 Content-Encoding 解压（gzip/deflate），拿不到 JSON 就换 UA 重试 3 轮，仍失败则提示「B 站接口没有返回 JSON（可能被风控或网络拦截），请重试」；B 站接口整条不可用时，解析会自动回退到 yt-dlp（实测同样能拿到全部格式）。

App 侧也加了兜底：引擎返回空串或被截断的结果会先自动重解析一次，仍不合法则显示「解析结果不完整，请重试」，不再出现看不懂的英文报错。
