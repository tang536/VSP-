## VSP 解析 v1.4.1

- 版本：versionCode 6 / versionName 1.4.1，minSdk 24 / targetSdk 36 / arm64-v8a
- 安装包：`VSP-Parse-v1.4.1.apk`，约 29 MB
- 与 v1.0 ~ v1.4 同一把正式证书，可直接覆盖安装

### 本版修复

1. **检查更新真正可用**：仓库已发布正式 Release，app 内点「检查更新」会拉到最新版本号、更新说明、安装包大小与发布时间，确认后自动下载并拉起系统安装器。
2. **下载完整性校验**：下载完成先校验 DownloadManager 的下载状态与字节数（对比 Release 中的安装包大小），不完整会提示重试，不会把半截包丢给安装器。
3. **下载结果可在重启后接续**：下载任务 id 持久化，即使中途退出 app，下载完成后依然能自动提示安装。
4. **弹窗信息更完整**：「发现新版本」显示版本号、包大小、发布时间与更新内容；「已是最新版本」新增「重新下载安装包」，方便修复安装。
5. **仓库无 Release 时给出明确提示**：不再显示成「检查更新失败」，而是「暂无可用更新」并给仓库入口。

### v1.4 起的主要能力

- 播放器控制条对齐主流播放器（时间/进度/总时长 + 静音、倍速、音量、全屏），支持全屏横屏播放
- HTML 兜底解析：非标准站点也能提取 m3u8 / mp4 / webm / flv，支持一层 iframe 与 JSON-LD
- 本地页 ⋮ 菜单（提取视频配乐 / 扫描本地媒体）、一行三个视频网格、独立扫描页（视频+音频+图片）
- 存储管理三行横向布局，点「下载文件」可查看、打开、删除每个已下载文件
- 音视频无损合并与配乐提取（MediaExtractor + MediaMuxer，等价 ffmpeg -c copy）

### 提示

首次更新需要允许「安装未知应用」权限，否则下载完成后无法自动拉起安装器。
