## VSP 解析 v1.4

- 版本：versionCode 5 / versionName 1.4，minSdk 24 / targetSdk 36 / arm64-v8a
- 安装包：`VSP-Parse-v1.4.apk`，约 29 MB
- 与 v1.0 ~ v1.3 同一把正式证书，可直接覆盖安装，无需卸载旧包

### 本次更新

1. **播放器控制条对齐主流播放器**：上行「已播时间 — 进度条 — 总时长」，下行「静音 / 倍速 / 音量滑杆 + 百分比 / 全屏」，黑底半透明叠在画面内，点击收起，3 秒无操作自动隐藏。
2. **新增全屏播放**：横屏 + 隐藏状态栏导航栏，进出全屏播放进度连续不重播。
3. **解析能力大改**：新增 HTML 兜底解析（反转义 `\/`、`\u002F`、`&amp;` → 正则提取 m3u8/mp4/webm/flv → 跟随一层 iframe → JSON-LD `contentUrl`），修复相对地址丢签名参数导致 403；Web 端 `/api/parse` 与 app 共用同一套逻辑。
4. **本地页瘦身**：去掉「重新扫描」按钮，改为右上角 ⋮ 菜单（提取视频配乐 / 扫描本地媒体）。
5. **新增本地视频页**：一行三个视频网格，卡片带时长角标与「提取配乐」按钮。
6. **新增扫描页**：左上角 ×、大图标、转圈进度、重新扫描 / 自定义扫描 / 扫描过滤设置；默认扫描全部视频 + 音频 + 图片。
7. **存储管理改横向三行**：缓存、下载文件、占用空间各一行，右侧对应清空按钮；点「下载文件」可查看每个已下载文件并单独打开或删除。
8. **检查更新接入 GitHub Releases**：从 `tang536/VSP-` 拉取最新版本、更新说明与安装包，确认后自动下载并用系统安装器安装。
9. **音视频合并 / 提取配乐**：用系统 `MediaExtractor + MediaMuxer` 做无损封装（官方 ffmpeg-kit 已停止分发，故改用系统能力，效果等价 `ffmpeg -c copy`）。

### 提示

首次安装需允许「安装未知应用」权限，否则更新下载完成后无法自动拉起安装器。
