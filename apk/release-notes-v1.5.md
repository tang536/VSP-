## VSP 解析 v1.5

- 版本：versionCode 7 / versionName 1.5，minSdk 24 / targetSdk 36 / arm64-v8a
- 安装包：`VSP-Parse-v1.5.apk`，约 29 MB
- 与 v1.0 ~ v1.4.1 同一把正式证书，可直接覆盖安装，**升级不会丢数据**

### 本次更新

1. **全新启动图标**：满幅橙色渐变圆角方块 + 白色 V，四角透明，彻底去掉旧图标四周的黑边；同时补上自适应图标（Android 8+ 不再被启动器补底）与圆形图标。
2. **点条目直接全屏观看**：视频 / 音频 / 图片点开就是全屏观看，不再是在页面里嵌一个小窗；顶部左侧是 backspace，点它退出观看，右侧显示这个文件的名字与类型。
3. **图片可缩放**：双指缩放（1x ~ 5x）、双击放大 / 还原、放大后单指拖动平移，拖不出屏幕。
4. **音量改为点图标才展开**：控制条默认只显示音量图标，点一下才出现滑杆与百分比，再点收起。
5. **扫描改为完全手动**：切换扫描目录（自定义文件夹 / 应用下载目录 / 系统下载目录 / 手动输入路径）、修改扫描过滤，都只更新范围提示，必须点「开始扫描」才会真的扫。
6. **新增扫描设置**：「每次扫描只保留本次结果」——勾选则扫描前清空上次结果，不勾选则与上次结果合并保留。
7. **数据不再丢**：扫描结果、最近一次解析结果（链接 + 标题 + 封面 + 格式列表）都落盘保存，退出重开或覆盖升级后自动恢复，不用重新扫、重新解析。
8. **更新下载可视化、可取消**：点更新后弹进度窗口，实时显示百分比与「已下载 / 总大小」，可随时「取消下载」，也可以「后台继续」；通知栏同步显示下载进度（已补 Android 13+ 通知权限申请）。
9. **更新互斥**：正在下载更新时，再点「检查更新」只会显示当前进度，不会重复检查、重复下载；中途退出 app 再进来会继续显示这次下载的进度。

### 提示

首次更新需要允许「安装未知应用」权限；Android 13+ 想在看通知栏进度需要允许通知。
