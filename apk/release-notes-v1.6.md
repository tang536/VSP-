## 本次更新（v1.6）

### 解析
- 修复 B 站、抖音等站点解析不出来：解析与下载统一改用桌面 UA，并按站点补 `Referer`
  - B 站此前用移动端 UA 请求，接口返回的 `formats` 是空数组，随后落到 HTML 兜底并报错；
    换成桌面 UA 后拿到 12 条视频流 + 3 条音频流（含 1080P），视频流自动标记需要合并音轨
  - B 站 CDN 会校验 Referer，缺了直接 403；下载链路也补上了站点请求头（实测：无 Referer 403，带 Referer 200）
- 抖音新增专用解析：走分享页 `_ROUTER_DATA` 里取 `play_addr`，`playwm` 自动换成 `play` 去水印，
  支持图集与原声；短链（`v.douyin.com`）先跟随跳转再识别作品 ID
- 快手、小红书、微博、西瓜、知乎、腾讯视频、优酷、A 站等站点补了 Referer 映射

### 界面（对齐系统相册 / 系统播放器）
- 播放器改成系统播放器风格：纯黑底、细线白图标、无背景控制条，进度条竖排贴左侧，
  时间分当前/总时长两行，顶栏左侧细线返回 + 文件名 + 分辨率/体积副标题
- 图片查看器补底部缩略图条（同批图片，可点击切换）+ 分享 / 信息 / 删除 / 更多四个操作
- 顶部与底部加渐变遮罩，白色图标压在亮画面上也看得清

### 更新
- 已是最新版本时只在顶部滑出轻提示「当前已是最新版本 vX」，不再弹带仓库信息的对话框
- 更新源增加 Gitee（`gitee.com/tang-rongqiang/VSP`）：GitHub 与 Gitee 同时查，取版本更高的那个；
  Gitee 走 OpenAPI 查 Release，仓库里没 Release 时读 `dist/latest.json` 兜底
- 更新下载改自建前台服务：通知栏除了进度条，还能看到**已下载 / 总大小**和**实时下载速度**，
  通知里直接有「取消下载」；应用内弹窗同步显示同一组数字
- 正在更新时点检查更新只会提示当前进度，不会重复检查、重复下载

### 头像与缓存
- 头像改为原图原样保存（不裁剪、不缩放、不重新编码），显示时才按需采样解码
- 点头像直接进全屏观看，可双指缩放；底部「更多」里更换或恢复默认头像
- 修复「缓存永远是 0」：缩略图以前只存内存，退出就没了；现在网络封面与本地首帧都落盘到
  `cacheDir/thumbs`，下次进来直接读文件；缓存统计同时算内部与外部缓存目录，清空时一起清

### 其它
- 大图解码按 2400px 采样，几千万像素的原图也不会 OOM
